# Computer Course Taxonomy

Use this as a routing aid, not as a claim about a particular school's syllabus.

## Operating Systems

Processes and threads, scheduling, synchronization, deadlocks, memory management, virtual memory, file systems, I/O, protection, and common calculations.

## Computer Networks

Layered models, physical and data-link concepts, Ethernet and VLANs, IP addressing and subnetting, routing, transport protocols, application protocols, network security, and packet-analysis reasoning.

## Computer Organization and Architecture

Data representation, instruction sets, CPU datapaths, control units, pipelines, caches, memory hierarchy, buses, I/O, interrupts, and performance calculations.

## Database Systems

Relational modeling, SQL, functional dependencies, normalization, transactions, concurrency control, recovery, indexing, and query reasoning.

## Programming and Data Structures

Complexity, arrays and linked structures, stacks and queues, trees, graphs, sorting, searching, recursion, debugging, and implementation trade-offs.

## Software Engineering and Web Development

Requirements, design, testing, version control, architecture, HTTP, frontend/backend responsibilities, databases, deployment concepts, and common debugging paths.

## Artificial Intelligence and Machine Learning

Problem formulation, search, probability, linear models, classification, regression, optimization, evaluation metrics, overfitting, feature processing, neural networks, and experiment interpretation.

## Digital Image Processing and Computer Vision

Image representation, sampling and quantization, enhancement, filtering, edge detection, frequency-domain methods, segmentation, morphology, feature extraction, image compression, geometric transforms, and evaluation of vision results.

## Digital Logic and Embedded Systems

Boolean algebra, combinational and sequential circuits, state machines, timing, memory devices, microcontrollers, peripherals, interrupts, and practical debugging.

## Topic Mapping Heuristics

- Repeated concepts across years receive higher priority.
- A teacher's explicit emphasis outranks frequency alone.
- A calculation or coding pattern should be paired with one worked example and one variation.
- Similar concepts should be compared in a compact matrix or contrast list.
- Mark topics that depend on a specific textbook, instruction set, protocol version, or lab environment as course-specific.
