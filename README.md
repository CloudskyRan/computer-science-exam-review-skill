# Computer Science Exam Review Skill

一个面向计算机科学专业课期末复习的 Codex Skill。它可以根据你提供的往年真题、复习提纲、课堂笔记和重点标注，整理考点、制定复习计划、生成练习题，并给出带推理过程的答案解析。

## 适用场景

- 根据真题和老师划定的重点，梳理高频考点和题型
- 将零散笔记整理为分层复习提纲
- 制定按天或按阶段执行的复习计划
- 生成选择题、简答题、计算题、代码题和综合题
- 对答案进行步骤化解析，指出易错点和需要向课程资料核对的内容

优先支持：

操作系统、计算机网络、计算机组成原理、数据库、数据结构与程序设计、软件工程与 Web、人工智能与机器学习、数字图像处理、数字逻辑和嵌入式系统。

## 使用方式

将 `computer-science-exam-review` 目录作为 Skill 安装或加载，然后直接用中文描述任务，并提供可用资料。例如：

```text
请根据我上传的《计算机网络》往年真题和老师划重点：
1. 按 A（必须掌握）、B（重点掌握）、C（了解即可）分级；
2. 总结常见题型和解题方法；
3. 制定 7 天复习计划；
4. 最后生成 10 道自测题，先不要显示答案。
```

资料不完整时，也可以只提供课程名称、考试范围和重点章节。Skill 会区分：

- `资料明确提到`：能够从用户资料直接确认的内容
- `高频基础`：有助于复习但未被当前资料直接证明的通用知识
- `待确认`：资料缺失、表述冲突或依赖具体教材和课程要求的内容

## 输出特点

默认输出包括：

1. 资料范围与可信度
2. A/B/C 重点地图
3. 复习安排和阶段目标
4. 分类型练习题
5. 答案、关键步骤和常见陷阱
6. 考前核对清单

Skill 不会保证某道题一定出现，也不会自行编造题号、页码、教师偏好、考试日期或分值比例。

## 隐私与公开边界

本仓库是公开仓库，只包含 Skill 规则、通用课程分类和使用说明，不包含：

- 往年试卷、课件、录音、答案或截图
- 从私有资料提取的全文或数据集
- 姓名、学号、联系方式等个人信息
- GitHub Token、密码或其他密钥

使用时，课程资料应只作为本地或当前会话输入。Skill 会先识别并隔离姓名、学号、联系方式、证件信息、账号、令牌、密码、二维码、签名、头像，以及文件名或路径中的身份信息；输出中不会复述这些内容，必要时以 `[已脱敏]` 替代。仍请确认你拥有处理相关课程资料的权限，且不要要求公开发布原始资料。
